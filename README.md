# 證件 / 存摺 A4 排版工具 (ID Card & Passbook Layout Master)

一個純前端運作、保護隱私且支援 PWA（Progressive Web App）的網頁應用程式。專為快速將身分證、健保卡、駕照、存摺等各類證件與文件自動切割、校正並排版至 A4 紙張而設計，支援導出高解析度 JPG、PNG 與 PDF 檔案。

---

## 💡 特點與亮點

- **🔒 隱私安全**：純前端運作，所有圖像處理（含圖像辨識與邊緣偵測）均在使用者瀏覽器本地端完成，圖片不會上傳至任何伺服器。
- **🤖 自動影像辨識**：支援在一張照片中自動偵測並切割出多個證件或存摺。
- **✏️ 手動調整與多框選**：內建編輯器，支援手動拖曳四角節點校正邊界、新增或刪除選取框。
- **📐 彈性排版尺寸**：
  - **自動放大填滿**：自動優化排版填滿空間。
  - **實際尺寸**：標準證件（85.6 × 54 mm）、存摺長邊（預設 142 mm）及自訂物件長邊。
- **🖨️ 列印與輸出設定**：
  - 自訂解析度（150 dpi / 200 dpi / 300 dpi）。
  - 可調整頁面邊距、物件間距。
  - 支援自動旋轉 90° 以最佳化空間利用。
  - 提供輔助裁切線（細邊框）開關。
- **📱 PWA 跨平台支援**：支援安裝至手機或電腦主畫面，可離線使用與相機直接拍照輸入。

## 🛠️ 使用說明

### 步驟 ①：選擇或拍攝圖片
- **選擇圖片**：可一次上傳一張或多張照片，或直接將照片拖曳至拖放區域。
- **拍照**：行動裝置可直接呼叫相機拍照。
- **自動偵測**：系統透過電腦視覺引擎自動定位照片中的證件與文件。

### 步驟 ②：檢查與手動微調
- **旋轉與類別設定**：可調整單一項目的旋轉角度，並可設定為「證件」、「存摺」或「其他物件」。
- **調整框選範圍**：若自動偵測不準確，可開啟編輯器進行四角點拖曳校正、新增框或刪除框。

### 步驟 ③：設定參數與匯出
1. 選擇**尺寸模式**（自動填滿或實際尺寸）。
2. 設定**解析度**（150 / 200 / 300 dpi）及頁面**邊距與間距**。
3. 勾選是否開啟**自動旋轉**與**裁切細邊框**。
4. 點擊按鈕輸出成 **JPG**、**PNG** 或 **PDF** 格式，亦可使用系統**分享/儲存**功能。

## 🚀 開發與部署

由於本專案為靜態網頁應用程式，無需複雜的後端環境 setup：

1. **本地執行**：
   使用任何靜態 Web 伺服器（例如 Live Server, HTTP Server, 或 Nginx）開啟專案根目錄即可。
   ```bash
   # 使用 npx 快速開啟本地伺服器範例
   npx serve .
   ```

2. **部署方式**：
   可直接部署至 GitHub Pages、Vercel、Netlify 等免費靜態網站託管平台。
